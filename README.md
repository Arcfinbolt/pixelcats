# Ember · Volt · Frost

A gentle pixel-art platformer with three cats, each with her own level:

- **Ember** breathes fire in a snowy village: melt ice and snowballs, light the lanterns and the big bonfire.
- **Volt** zaps lightning in an old powerhouse: power up gates, clamp rolling cable spools, light the lamps and the generator.
- **Frost** charges a freeze in a hot-springs valley: freeze water into bridges, bubbles into ice balls and steam into clouds.

No damage and no falling deaths: obstacles just bump you back, and water is for swimming.

**Play:** open `index.html` in a browser, or visit the GitHub Pages site for this repository.

**Controls:** arrow keys to walk, Shift to run, Z or Space to jump, X for the cat's power. On phones, on-screen buttons appear.

Art and effects are generated in code with the [Codixel](https://github.com/mankidev/codixel) pixel-art library.
